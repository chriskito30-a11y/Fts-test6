Politique de confidentialité

Cette page explique simplement comment l’association Fais Ton Show utilise les données dans son application : inscription, espace membre, ressources, messages, notifications, rappels, sondages et organisation des activités.

Connexion / inscription Retour accueil FAQ

1. Responsable du traitement

Le responsable du traitement est l’association Fais Ton Show, école des arts de la scène.

Pour toute demande liée aux données personnelles : contact@faistonshow.fr.

2. Données collectées

Selon ton utilisation, l’application peut traiter :

  • identité : prénom, nom, adresse e-mail, téléphone ;
  • informations d’inscription : activités, disciplines, groupes, sous-catégories, statut du compte ;
  • données enfant si un parent inscrit un mineur : prénom, nom, date de naissance, téléphone optionnel, groupes/activités ;
  • données de connexion Firebase : identifiant technique UID, adresse e-mail, date de création ;
  • messages privés, forum, réactions, sondages, réponses, annonces lues/non lues ;
  • ressources pédagogiques consultées, préférences de rappels, notifications et paramètres PWA ;
  • données techniques nécessaires : abonnement push, identifiants de notification, cache local/offline.

3. Pourquoi ces données sont utilisées

  • gérer les inscriptions, les validations et les comptes membres ;
  • donner accès aux bons groupes, ressources, messages, forums et sondages ;
  • organiser les cours, répétitions, événements, rappels et spectacles ;
  • envoyer des notifications importantes ;
  • faciliter la communication entre administration, professeurs, parents et élèves ;
  • sécuriser l’accès à l’application et limiter l’accès aux personnes autorisées.

4. Base légale

Les traitements reposent principalement sur la gestion de l’adhésion et des services proposés par l’association, l’intérêt légitime d’organisation interne et, lorsque nécessaire, le consentement de l’utilisateur ou du responsable légal.

Pour les mineurs, l’inscription est effectuée par un parent ou responsable légal. Pour les enfants de moins de 15 ans, le consentement du parent/responsable légal est demandé lors de l’inscription.

5. Qui peut accéder aux données ?

  • l’administration Fais Ton Show, pour gérer les inscriptions et l’organisation ;
  • les professeurs, uniquement pour les informations utiles à leurs groupes, ressources et communications ;
  • les membres, uniquement pour leur propre espace et les espaces communautaires auxquels ils ont accès ;
  • les prestataires techniques nécessaires au fonctionnement de l’application.

6. Services techniques utilisés

  • Firebase : authentification, base de données temps réel, éventuel stockage technique ;
  • Cloudflare Workers / KV : notifications push, sécurisation de certains accès, domaine ;
  • Brevo / Make : e-mails transactionnels liés à l’inscription et à la validation ;
  • Cloudinary : hébergement de certains médias si utilisés ;
  • OneDrive : dossiers vidéos Danse, accessibles selon les droits.

7. Durée de conservation

Les données sont conservées pendant la durée nécessaire à la gestion de l’adhésion, des cours et de l’organisation de l’association. À la demande de l’utilisateur, le compte et les données personnelles rattachées peuvent être supprimés depuis l’espace membre, sauf obligation légale ou besoin légitime limité de conservation.

8. Tes droits

Tu peux demander ou effectuer depuis l’espace membre :

  • l’accès à tes données via l’export JSON ;
  • la rectification de tes informations ;
  • la modification de ton adresse e-mail ;
  • la suppression d’un enfant associé ;
  • la désactivation des notifications ;
  • la suppression de ton compte et des données rattachées à ton UID.

Tu peux aussi écrire à contact@faistonshow.fr. Une réponse est apportée dans les délais prévus par la réglementation.

9. Notifications et installation PWA

Les notifications push sont facultatives. Elles servent à recevoir les messages importants : inscriptions, ressources, rappels, changements d’organisation, événements ou messages. Elles peuvent être désactivées à tout moment depuis “Mon compte”.

10. Cookies et traceurs

L’application utilise les éléments techniques nécessaires à son fonctionnement : session Firebase, cache PWA, stockage local utile à l’expérience et notifications. Aucun traceur publicitaire n’est nécessaire au fonctionnement de l’espace membre. Si des outils marketing étaient ajoutés plus tard, un consentement spécifique serait demandé lorsque nécessaire.

11. Sécurité

L’accès à l’application est protégé par authentification Firebase. Les droits sont séparés entre membres, professeurs et administration. Les liens privés et webhooks sensibles sont servis côté Cloudflare Workers et ne sont pas exposés dans le code public.
