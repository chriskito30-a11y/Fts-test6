Comment une mission devient utile

Une mission doit aider à mieux venir en cours, mieux répéter, mieux écouter ou mieux faire équipe.

1Déclaratif

L’élève ou le parent coche une action faite : sac prêt, planning vérifié, ressource lue.

2Automatique

Plus tard : consulter une ressource, entrer un code ou activer les notifications pourra valider une étape.

3Validation prof

Pour les défis artistiques sensibles : texte su, chanson prête, chorégraphie travaillée.
