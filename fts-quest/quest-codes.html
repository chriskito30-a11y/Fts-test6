Comment un code peut être utilisé

Un code utile doit être ciblé, limité et lié à une vraie action FTS.

01Créer un code

Nom, code, XP, récompense, catégorie ciblée, date d’expiration.

02Cibler un groupe

Public, activité, sous-catégorie, prof, événement ou groupe concerné.

03Limiter l’usage

Une fois par membre, quota total, période active, désactivation rapide.

04Analyser

Nombre d’utilisations, historique, récompenses distribuées, erreurs.
